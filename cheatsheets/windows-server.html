Rollen & Features

Alle Befehle in einer PowerShell als Administrator. Gilt für Windows Server 2019/2022/2025.

BefehlBeschreibung
Get-WindowsFeatureAlle Rollen und Features mit Status
Get-WindowsFeature | Where-Object InstalledNur installierte
Install-WindowsFeature Web-Server -IncludeManagementToolsRolle inkl. Verwaltungstools installieren
Uninstall-WindowsFeature Web-ServerRolle entfernen
sconfigMenü für die Grundkonfiguration (v. a. Server Core)
Rename-Computer -NewName SRV01 -RestartServer umbenennen
Get-ScheduledTask | Where-Object State -eq ReadyGeplante Aufgaben
ServerManager.exeServer-Manager öffnen (Alternative: Windows Admin Center im Browser)

AD DS einrichten

BefehlBeschreibung
Install-WindowsFeature AD-Domain-Services -IncludeManagementToolsAD-DS-Rolle installieren
Install-ADDSForest -DomainName firma.local -InstallDnsNeue Gesamtstruktur (erster DC)
Install-ADDSDomainController -DomainName firma.local -InstallDns -Credential (Get-Credential)Weiteren DC hinzufügen
Test-ADDSDomainControllerInstallation -DomainName firma.localVoraussetzungen prüfen

DNS

BefehlBeschreibung
Install-WindowsFeature DNS -IncludeManagementToolsDNS-Rolle installieren
Get-DnsServerZoneZonen anzeigen
Add-DnsServerPrimaryZone -Name firma.local -ReplicationScope DomainAD-integrierte Zone anlegen
Add-DnsServerPrimaryZone -NetworkId 192.168.10.0/24 -ReplicationScope DomainReverse-Lookup-Zone anlegen
Add-DnsServerResourceRecordA -ZoneName firma.local -Name web -IPv4Address 192.168.10.20 -CreatePtrA-Record mit PTR
Add-DnsServerResourceRecordCName -ZoneName firma.local -Name www -HostNameAlias web.firma.localCNAME anlegen
Get-DnsServerResourceRecord -ZoneName firma.localEinträge einer Zone
Remove-DnsServerResourceRecord -ZoneName firma.local -Name web -RRType AEintrag löschen
Set-DnsServerForwarder -IPAddress 1.1.1.1, 9.9.9.9Weiterleitungen setzen
Clear-DnsServerCacheServer-Cache leeren
Clear-DnsClientCacheClient-Cache leeren (wie ipconfig /flushdns)

IIS (Webserver)

BefehlBeschreibung
Install-WindowsFeature Web-Server -IncludeManagementToolsIIS installieren
Import-Module WebAdministrationModul für IIS-Verwaltung laden (alternativ IISAdministration)
Get-WebsiteWebsites anzeigen
New-Website -Name "Intranet" -Port 80 -HostHeader intranet.firma.local -PhysicalPath C:\inetpub\intranetWebsite anlegen
New-WebAppPool -Name "IntranetPool"Anwendungspool anlegen
Start-Website / Stop-Website -Name "Intranet"Website starten / stoppen
Restart-WebAppPool -Name "IntranetPool"Anwendungspool neu starten
New-WebBinding -Name "Intranet" -Protocol https -Port 443 -HostHeader intranet.firma.local -SslFlags 1HTTPS-Bindung (SNI) hinzufügen
iisresetIIS komplett neu starten
C:\inetpub\logs\LogFilesStandardpfad der Zugriffsprotokolle
