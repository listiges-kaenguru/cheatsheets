Grundlagen & Begriffe

Die Cmdlets stammen aus dem Modul ActiveDirectory (RSAT: Add-WindowsCapability -Online -Name Rsat.ActiveDirectory.DS-LDS.Tools~~~~0.0.1.0, auf Servern Install-WindowsFeature RSAT-AD-PowerShell).

Begriff / BefehlBeschreibung
Domain Controller (DC)Server, der das Verzeichnis und die Anmeldung bereitstellt
Organizational Unit (OU)Container zum Strukturieren von Objekten und Verknüpfen von GPOs
Forest / Domain / TrustGesamtstruktur / Verwaltungsgrenze / Vertrauensstellung zwischen Domänen
FSMO-RollenFünf Sonderrollen, die jeweils nur ein DC innehat
Distinguished Name (DN)Eindeutiger Pfad, z. B. CN=Max,OU=Vertrieb,DC=firma,DC=local
Import-Module ActiveDirectoryModul laden (geschieht meist automatisch)
Get-ADDomain / Get-ADForestInformationen zu Domäne / Gesamtstruktur
Get-ADDomainController -Filter *Alle Domain Controller
netdom query fsmoFSMO-Rolleninhaber anzeigen
dsa.msc / gpmc.msc / dssite.mscKonsolen: Benutzer & Computer / Gruppenrichtlinien / Standorte

Benutzer

BefehlBeschreibung
Get-ADUser -Identity mmuster -Properties *Benutzer mit allen Attributen
Get-ADUser -Filter "Surname -like 'Mu*'"Benutzer per Filter suchen
Get-ADUser -Filter * -SearchBase "OU=Vertrieb,DC=firma,DC=local"Alle Benutzer einer OU
New-ADUser -Name "Max Muster" -SamAccountName mmuster -UserPrincipalName mmuster@firma.local -Path "OU=Vertrieb,DC=firma,DC=local" -AccountPassword (Read-Host -AsSecureString "Passwort") -Enabled $trueBenutzer anlegen
Set-ADUser mmuster -Department "Vertrieb" -Title "Berater"Attribute ändern
Set-ADAccountPassword mmuster -Reset -NewPassword (Read-Host -AsSecureString)Passwort zurücksetzen
Set-ADUser mmuster -ChangePasswordAtLogon $truePasswortänderung bei nächster Anmeldung erzwingen
Unlock-ADAccount mmusterGesperrtes Konto entsperren
Search-ADAccount -LockedOutGesperrte Konten finden
Search-ADAccount -AccountInactive -TimeSpan 90.00:00:00 -UsersOnlySeit 90 Tagen inaktive Benutzer
Disable-ADAccount mmuster / Enable-ADAccount mmusterKonto deaktivieren / aktivieren
Remove-ADUser mmusterBenutzer löschen
Get-ADPrincipalGroupMembership mmusterGruppenmitgliedschaften eines Benutzers

Gruppen

BefehlBeschreibung
Get-ADGroup -Filter "Name -like 'GG_*'"Gruppen suchen
Get-ADGroupMember "GG_Vertrieb" -RecursiveMitglieder inkl. verschachtelter Gruppen
New-ADGroup -Name "GG_Vertrieb" -GroupScope Global -GroupCategory Security -Path "OU=Gruppen,DC=firma,DC=local"Sicherheitsgruppe anlegen
Add-ADGroupMember "GG_Vertrieb" -Members mmuster, ebergMitglieder hinzufügen
Remove-ADGroupMember "GG_Vertrieb" -Members mmusterMitglied entfernen
Global / DomainLocal / UniversalGruppenbereiche (Empfehlung AGDLP: Konten → globale → domänenlokale Gruppen → Berechtigungen)

OUs, Suche & Diagnose

BefehlBeschreibung
Get-ADOrganizationalUnit -Filter * | Select-Object DistinguishedNameAlle OUs
New-ADOrganizationalUnit -Name "Vertrieb" -Path "DC=firma,DC=local"OU anlegen (standardmäßig vor Löschen geschützt)
Set-ADOrganizationalUnit "OU=Vertrieb,DC=firma,DC=local" -ProtectedFromAccidentalDeletion $falseLöschschutz aufheben
Move-ADObject "CN=Max Muster,OU=Alt,DC=firma,DC=local" -TargetPath "OU=Vertrieb,DC=firma,DC=local"Objekt verschieben
Get-ADObject -Filter * -IncludeDeletedObjects -SearchBase (Get-ADDomain).DeletedObjectsContainerGelöschte Objekte (AD-Papierkorb)
Restore-ADObject -Identity GUIDGelöschtes Objekt wiederherstellen
repadmin /replsummaryReplikationsstatus aller DCs
repadmin /syncall /AdePReplikation anstoßen
dcdiag /vDiagnose eines Domain Controllers
