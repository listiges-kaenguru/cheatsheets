Sitzungen

Alle Tastenkürzel beginnen mit dem Präfix Ctrl+a, danach wird die zweite Taste gedrückt (Präfix loslassen).

BefehlBeschreibung
screenNeue Sitzung starten
screen -S nameBenannte Sitzung starten
screen -lsSitzungen auflisten
screen -r nameGetrennte Sitzung fortsetzen (Name oder PID)
screen -dr nameSitzung woanders trennen und hier fortsetzen
screen -x nameAn bereits verbundene Sitzung zusätzlich anhängen (Mehrfachanzeige)
screen -d nameSitzung von außen trennen
screen -dmS name befehlSitzung im Hintergrund mit Befehl starten
screen -S name -X quitSitzung von außen beenden
screen -S name -X stuff "befehl\n"Befehl in eine laufende Sitzung schicken
screen -L -S nameSitzung mit Protokoll in screenlog.0 starten
Ctrl+a dSitzung trennen (Detach), Programme laufen weiter
exitAktuelles Fenster bzw. letzte Shell beenden
