Kommandozeile & Meta-Befehle

SQLite speichert eine ganze Datenbank in einer Datei. Meta-Befehle beginnen mit . und brauchen kein Semikolon.

BefehlBeschreibung
sqlite3 daten.dbDatenbank öffnen (wird bei Bedarf angelegt)
sqlite3 daten.db "SELECT * FROM t;"Einzelne Abfrage direkt ausführen
sqlite3 :memory:Reine In-Memory-Datenbank
.helpAlle Meta-Befehle
.tablesTabellen auflisten
.schema tabelleCREATE-Anweisung einer Tabelle
.schemaSchema der gesamten Datenbank
.databasesAngehängte Datenbanken und Dateien
.mode boxAusgabe als Tabelle (auch column, csv, json, markdown)
.headers onSpaltenüberschriften anzeigen
.nullvalue NULLDarstellung von NULL festlegen
.timer onAusführungszeit anzeigen
.read skript.sqlSQL-Datei ausführen
.quitBeenden

Tabellen & Datentypen

BefehlBeschreibung
CREATE TABLE kunden (id INTEGER PRIMARY KEY, name TEXT NOT NULL, email TEXT UNIQUE, erstellt TEXT DEFAULT (datetime('now')));Tabelle anlegen (INTEGER PRIMARY KEY zählt automatisch hoch)
CREATE TABLE IF NOT EXISTS t (...);Nur anlegen, wenn nicht vorhanden
CREATE TABLE bestellungen (id INTEGER PRIMARY KEY, kunde_id INTEGER REFERENCES kunden(id));Fremdschlüssel
PRAGMA foreign_keys = ON;Fremdschlüssel erzwingen (je Verbindung nötig)
ALTER TABLE kunden ADD COLUMN telefon TEXT;Spalte hinzufügen
ALTER TABLE kunden RENAME COLUMN telefon TO tel;Spalte umbenennen
ALTER TABLE kunden RENAME TO kunde;Tabelle umbenennen
CREATE INDEX idx_name ON kunden(name);Index anlegen
DROP TABLE kunden;Tabelle löschen
Speicherklassen
TEXTZeichenkette
INTEGERGanzzahl
REALFließkommazahl
BLOBBinärdaten
NULLKein Wert (SQLite ist dynamisch typisiert)

Abfragen & Daten

BefehlBeschreibung
SELECT * FROM kunden WHERE name LIKE 'M%' ORDER BY name LIMIT 10;Filtern, sortieren, begrenzen
SELECT land, COUNT(*) FROM kunden GROUP BY land HAVING COUNT(*) > 5;Gruppieren und filtern
SELECT k.name, b.id FROM kunden k JOIN bestellungen b ON b.kunde_id = k.id;Join
INSERT INTO kunden (name, email) VALUES ('Max', 'max@example.org');Zeile einfügen
INSERT INTO kunden (name) VALUES ('A'), ('B');Mehrere Zeilen
INSERT INTO kunden (email, name) VALUES ('m@x', 'Max') ON CONFLICT(email) DO UPDATE SET name = excluded.name;Upsert
UPDATE kunden SET name = 'Maria' WHERE id = 1;Aktualisieren
DELETE FROM kunden WHERE id = 1;Löschen
SELECT json_extract(daten, '$.feld') FROM logs;Wert aus JSON-Spalte lesen
EXPLAIN QUERY PLAN SELECT * FROM kunden WHERE name = 'Max';Prüfen, ob ein Index genutzt wird
BEGIN; ... COMMIT; / ROLLBACK;Transaktion

Import, Export & Wartung

BefehlBeschreibung
.import --csv daten.csv kundenCSV in eine Tabelle importieren
.once ausgabe.csvNächste Ausgabe in Datei schreiben
.mode csv / .output daten.csvAusgabeformat/-ziel für Export setzen
.dumpGanze Datenbank als SQL ausgeben (Backup)
sqlite3 daten.db .dump > backup.sqlSQL-Backup auf der Shell
sqlite3 neu.db < backup.sqlBackup einspielen
.backup sicherung.dbKonsistente Binärsicherung (auch bei laufendem Zugriff)
VACUUM;Datei verkleinern und aufräumen
PRAGMA integrity_check;Datenbank auf Fehler prüfen
PRAGMA journal_mode = WAL;Write-Ahead-Logging (bessere Parallelität)
PRAGMA table_info(kunden);Spalten einer Tabelle anzeigen
