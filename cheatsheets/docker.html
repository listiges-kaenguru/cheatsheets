Netzwerke & Volumes

BefehlBeschreibung
docker network lsNetzwerke auflisten
docker network create netzBridge-Netzwerk anlegen
docker network connect netz webContainer mit Netzwerk verbinden
docker run --network netz …Container in bestimmtem Netzwerk starten (Container erreichen sich per Name)
docker volume lsVolumes auflisten
docker volume create datenVolume anlegen
docker run -v daten:/var/lib/mysql …Named Volume einhängen
docker run -v /host/pfad:/container/pfad:ro …Host-Verzeichnis nur lesend einhängen
docker volume inspect datenDetails eines Volumes
docker volume rm datenVolume löschen

Compose

Aktuell heißt der Befehl docker compose (Plugin). Das alte docker-compose (mit Bindestrich) ist die abgekündigte v1.

BefehlBeschreibung
docker compose up -dDienste aus compose.yaml im Hintergrund starten
docker compose up -d --buildVor dem Start neu bauen
docker compose downDienste stoppen und Container/Netzwerke entfernen
docker compose down -vZusätzlich Volumes entfernen
docker compose psStatus der Dienste
docker compose logs -f dienstLogs eines Dienstes verfolgen
docker compose exec dienst shShell in einem Dienst öffnen
docker compose pullImages aller Dienste aktualisieren
docker compose restart dienstEinzelnen Dienst neu starten
docker compose configZusammengeführte Konfiguration prüfen
docker compose run --rm dienst befehlEinmaligen Befehl ausführen
