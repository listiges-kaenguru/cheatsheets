Verbinden

BefehlBeschreibung
ssh benutzer@hostVerbinden
ssh -p 2222 benutzer@hostAnderer Port
ssh -i ~/.ssh/id_ed25519 benutzer@hostBestimmten Schlüssel verwenden
ssh -J sprunghost benutzer@zielÜber Jump-Host verbinden
ssh benutzer@host 'befehl'Befehl remote ausführen
ssh -t benutzer@host 'sudo htop'Terminal erzwingen (für interaktive Befehle)
ssh -v / ssh -vvvDebug-Ausgabe bei Verbindungsproblemen
ssh -C benutzer@hostKompression (langsame Leitungen)
ssh -X benutzer@hostX11-Weiterleitung (grafische Programme)
ssh-keygen -R hostVeralteten Host-Schlüssel aus known_hosts entfernen
ssh-keyscan hostHost-Schlüssel eines Servers abrufen
Enter ~ .Hängende Verbindung sofort trennen

Schlüssel & Agent

BefehlBeschreibung
ssh-keygen -t ed25519 -C "kommentar"Ed25519-Schlüssel erzeugen (empfohlen)
ssh-keygen -t rsa -b 4096RSA-Schlüssel für ältere Systeme
ssh-keygen -t ed25519-skSchlüssel auf FIDO2-Sicherheitsstick
ssh-keygen -p -f ~/.ssh/id_ed25519Passphrase ändern
ssh-keygen -lf ~/.ssh/id_ed25519.pubFingerabdruck anzeigen
ssh-keygen -y -f ~/.ssh/id_ed25519Öffentlichen Schlüssel aus privatem erzeugen
ssh-copy-id benutzer@hostÖffentlichen Schlüssel auf Server übertragen
ssh-copy-id -i ~/.ssh/id_ed25519.pub benutzer@hostBestimmten Schlüssel übertragen
eval "$(ssh-agent -s)"SSH-Agent starten
ssh-add / ssh-add -t 1h ~/.ssh/id_ed25519Schlüssel zum Agent hinzufügen (optional befristet)
ssh-add -l / ssh-add -DGeladene Schlüssel anzeigen / alle entfernen
chmod 700 ~/.ssh && chmod 600 ~/.ssh/authorized_keysRichtige Rechte (sonst verweigert sshd die Schlüssel)

Tunnel & Port-Weiterleitung

BefehlBeschreibung
ssh -L 8080:localhost:80 benutzer@hostLokal: localhost:8080 → Port 80 auf dem Server
ssh -L 5432:db.intern:5432 benutzer@sprunghostInternen Datenbankserver über Sprunghost erreichen
ssh -R 8080:localhost:3000 benutzer@hostRemote: Server-Port 8080 → lokaler Port 3000
ssh -D 1080 benutzer@hostSOCKS-Proxy auf localhost:1080
ssh -N -L 8080:localhost:80 benutzer@hostNur Tunnel, keine Shell
ssh -f -N -L 8080:localhost:80 benutzer@hostTunnel im Hintergrund

Dateien übertragen

BefehlBeschreibung
scp datei benutzer@host:/pfad/Datei hochladen (nutzt seit OpenSSH 9.0 intern SFTP)
scp benutzer@host:/pfad/datei .Datei herunterladen
scp -r ordner benutzer@host:/pfad/Ordner rekursiv kopieren
scp -P 2222 datei benutzer@host:/pfad/Anderer Port (großes -P)
sftp benutzer@hostInteraktive SFTP-Sitzung
rsync -avP ordner/ benutzer@host:/pfad/Synchronisieren über SSH (siehe rsync)
sshfs benutzer@host:/pfad /mnt/remoteEntferntes Verzeichnis einhängen

Server (sshd) absichern

Eintrag / BefehlBeschreibung
/etc/ssh/sshd_config.d/*.confEigene Einstellungen hier ablegen (erster Treffer gilt)
PermitRootLogin noKeine Root-Anmeldung
PasswordAuthentication noNur Schlüssel-Anmeldung (vorher Schlüssel testen!)
KbdInteractiveAuthentication noKeine Tastatur-interaktive Anmeldung
AllowUsers admin deployNur bestimmte Benutzer zulassen
MaxAuthTries 3Anmeldeversuche pro Verbindung begrenzen
sudo sshd -tKonfiguration prüfen, bevor der Dienst neu gestartet wird
sudo systemctl reload sshdKonfiguration übernehmen (Debian/Ubuntu: ssh)
sudo sshd -T | grep -i passwordauthTatsächlich wirksame Einstellung anzeigen
