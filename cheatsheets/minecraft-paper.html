Hilfe & Namespaces

In der Server-Console Befehle ohne führenden / eingeben (z. B. op Steve), im Spiel-Chat mit /. Ein Kürzel „InGame“ heißt: nur als Spieler sinnvoll; „Console“: nur in der Console; ohne Kürzel: beides.

BefehlBeschreibung
helpHilfe-Index mit allen Befehlen
help [n]Seite n der Hilfe
help [befehl]Beschreibung und Syntax eines Befehls, z. B. help build
help FluffyLobbyAlle Befehle von FluffyLobby
help Paper / help BukkitBefehle von Paper bzw. Bukkit
help MinecraftAlle Vanilla-Befehle
minecraft:[befehl]Vanilla-Befehl erzwingen, falls ein Plugin ihn überschreibt (z. B. minecraft:tp)
bukkit:[befehl] / paper:[befehl]Bukkit- bzw. Paper-Variante erzwingen (z. B. bukkit:pl)

Server-Start & Console

BefehlBeschreibung
java -Xms4G -Xmx4G -jar paper.jar --noguiServer starten (Xms = Xmx, RAM nach Bedarf anpassen)
-XX:+UseG1GC -XX:+ParallelRefProcEnabled -XX:MaxGCPauseMillis=200Auszug aus „Aikar's Flags“ (vor -jar einfügen)
eula=trueIn eula.txt setzen, sonst startet der Server nicht
screen -S minecraft / screen -r minecraftServer in Screen starten / wieder anhängen (siehe Screen-Cheatsheet)
Ctrl+a d ConsoleConsole verlassen, Server läuft weiter
stop ConsoleServer sauber herunterfahren (speichert alle Welten)
restart ConsoleNeustart (benötigt restart-script in spigot.yml)
save-all / save-all flushWelten speichern / speichern und auf Abschluss warten (vor Backups)
save-off / save-onAuto-Save aus- / einschalten (z. B. während eines Backups)
say [nachricht]Nachricht an alle Spieler senden
reloadLädt nur Datapacks neu (Vanilla), keine Plugins und keine Server-Configs
tail -f logs/latest.logLog live mitlesen (Linux-Shell, nicht Server-Console)
