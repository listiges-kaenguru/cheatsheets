Grundlagen

In der Hilfezeile steht ^ für Ctrl und M- für Alt (Meta). Die Kürzel gelten für nano ab Version 5.

BefehlBeschreibung
nano dateiDatei öffnen (oder neu anlegen)
nano +42 dateiDatei öffnen, Cursor in Zeile 42
nano -l dateiMit Zeilennummern öffnen
nano -v dateiNur lesend öffnen
sudo -e datei / sudoedit dateiSystemdatei sicher bearbeiten (Editor läuft ohne root-Rechte)
Ctrl+sSpeichern
Ctrl+oSpeichern unter (Dateiname abfragen)
Ctrl+xBeenden (fragt bei Änderungen nach)
Ctrl+rAndere Datei an der Cursorposition einfügen
Ctrl+gHilfe anzeigen

Navigation

TastenkürzelBeschreibung
Ctrl+a / Ctrl+eZeilenanfang / Zeilenende
Ctrl+y / Ctrl+vEine Seite zurück / vor
Alt+\Zum Dateianfang
Alt+/Zum Dateiende
Ctrl+_Zu Zeile (und Spalte) springen
Alt+]Zur passenden Klammer
Ctrl+cCursorposition anzeigen

Bearbeiten

TastenkürzelBeschreibung
Alt+aMarkierung beginnen/beenden (danach mit Pfeiltasten markieren)
Ctrl+kZeile bzw. Markierung ausschneiden
Alt+6Zeile bzw. Markierung kopieren
Ctrl+uEinfügen
Alt+uRückgängig (Undo)
Alt+eWiederherstellen (Redo)
Ctrl+DelWort rechts löschen
Alt+3Zeile bzw. Markierung aus-/einkommentieren
Tab / Shift+TabMarkierung ein-/ausrücken
Ctrl+jAbsatz umbrechen (Justify)

Suchen & Ersetzen

TastenkürzelBeschreibung
Ctrl+wVorwärts suchen
Ctrl+qRückwärts suchen
Alt+w / Alt+qNächster / vorheriger Treffer
Ctrl+\Suchen und ersetzen
Alt+rIm Suchdialog: reguläre Ausdrücke umschalten
Alt+cIm Suchdialog: Groß-/Kleinschreibung beachten

Extras & Konfiguration

BefehlBeschreibung
Alt+nZeilennummern ein-/ausblenden
Alt+pLeerzeichen/Tabs sichtbar machen
Alt+sWeiches Scrollen ein/aus
Ctrl+tExternen Befehl ausführen (Ausgabe wird eingefügt)
F12Rechtschreibprüfung (benötigt spell/hunspell)
~/.config/nano/nanorc / ~/.nanorcPersönliche Konfigurationsdatei
set linenumbersnanorc: Zeilennummern immer anzeigen
set tabsize 4nanorc: Tabbreite 4
set tabstospacesnanorc: Tabs als Leerzeichen einfügen
set autoindentnanorc: Automatisch einrücken
set mousenanorc: Mausunterstützung aktivieren
include "/usr/share/nano/*.nanorc"nanorc: Syntaxhervorhebung für alle mitgelieferten Sprachen
