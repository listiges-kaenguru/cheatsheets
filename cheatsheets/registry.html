Grundlagen

Vor Änderungen den betroffenen Schlüssel exportieren (reg export). Fehlerhafte Einträge können das System unbrauchbar machen.

BegriffBeschreibung
regeditGrafischer Registrierungs-Editor
HKEY_LOCAL_MACHINE / HKLMSystemweite Einstellungen (Software, Dienste, Hardware)
HKEY_CURRENT_USER / HKCUEinstellungen des angemeldeten Benutzers
HKEY_USERS / HKUProfile aller geladenen Benutzer
HKEY_CLASSES_ROOT / HKCRDateizuordnungen und COM-Klassen (Zusammenführung aus HKLM und HKCU)
HKEY_CURRENT_CONFIG / HKCCAktuelles Hardwareprofil
Datentypen
REG_SZZeichenkette
REG_EXPAND_SZZeichenkette mit Umgebungsvariablen wie %SystemRoot%
REG_MULTI_SZListe von Zeichenketten
REG_DWORD / REG_QWORD32- / 64-Bit-Zahl
REG_BINARYBinärdaten

reg.exe (CMD)

BefehlBeschreibung
reg query HKLM\SOFTWARE\Microsoft\Windows\CurrentVersionSchlüssel mit Werten anzeigen
reg query HKCU\Software /s /f "suchbegriff"Rekursiv suchen
reg query HKLM\SOFTWARE\Programm /v WertnameEinzelnen Wert anzeigen
reg add HKCU\Software\Programm /v Wertname /t REG_SZ /d "Daten" /fWert anlegen oder ändern
reg add HKCU\Software\Programm /v Aktiv /t REG_DWORD /d 1 /fDWORD-Wert setzen
reg delete HKCU\Software\Programm /v Wertname /fWert löschen
reg delete HKCU\Software\Programm /fSchlüssel samt Inhalt löschen
reg export HKCU\Software\Programm sicherung.reg /ySchlüssel in .reg-Datei exportieren
reg import sicherung.reg.reg-Datei importieren
reg copy HKCU\Software\Alt HKCU\Software\Neu /sSchlüssel kopieren
reg save HKLM\SOFTWARE sw.hivZweig als Hive-Datei sichern
reg load HKU\Offline C:\Users\name\NTUSER.DATHive eines anderen Benutzers laden
reg unload HKU\OfflineGeladenen Hive wieder entladen
reg query \\PC01\HKLM\SOFTWARERegistry eines Remote-Rechners (Dienst „Remoteregistrierung“ nötig)

PowerShell

BefehlBeschreibung
Get-ChildItem HKCU:\SoftwareUnterschlüssel auflisten
Get-ItemProperty HKCU:\Software\ProgrammAlle Werte eines Schlüssels
Get-ItemPropertyValue HKCU:\Software\Programm -Name WertnameEinzelnen Wert lesen
New-Item HKCU:\Software\Programm -ForceSchlüssel anlegen
New-ItemProperty HKCU:\Software\Programm -Name Aktiv -PropertyType DWord -Value 1Wert mit Typ anlegen
Set-ItemProperty HKCU:\Software\Programm -Name Aktiv -Value 0Wert ändern
Remove-ItemProperty HKCU:\Software\Programm -Name AktivWert löschen
Remove-Item HKCU:\Software\Programm -RecurseSchlüssel löschen
Test-Path HKCU:\Software\ProgrammExistiert der Schlüssel?

Wichtige Schlüssel

PfadInhalt
HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\RunAutostart für alle Benutzer
HKCU\Software\Microsoft\Windows\CurrentVersion\RunAutostart des aktuellen Benutzers
HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\RunOnceEinmaliger Start beim nächsten Anmelden
HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\UninstallInstallierte Programme (64 Bit)
HKLM\SOFTWARE\WOW6432Node\Microsoft\Windows\CurrentVersion\UninstallInstallierte Programme (32 Bit)
HKLM\SYSTEM\CurrentControlSet\ServicesDienste und Treiber
HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersionWindows-Version, Build, Produktname
HKLM\SOFTWARE\Policies / HKCU\Software\PoliciesDurch Gruppenrichtlinien gesetzte Werte
HKLM\SYSTEM\CurrentControlSet\Control\Terminal ServerRemotedesktop-Einstellungen (fDenyTSConnections)
HKCU\Environment / HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\EnvironmentUmgebungsvariablen Benutzer / System
