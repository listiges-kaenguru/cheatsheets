tar

BefehlBeschreibung
tar -cvf archiv.tar dateienArchiv erstellen
tar -czvf archiv.tar.gz verzeichnis/Mit gzip komprimieren
tar -cjvf archiv.tar.bz2 verzeichnis/Mit bzip2 komprimieren
tar -cJvf archiv.tar.xz verzeichnis/Mit xz komprimieren (klein, langsam)
tar --zstd -cvf archiv.tar.zst verzeichnis/Mit zstd komprimieren (schnell, gut)
tar -caf archiv.tar.xz verzeichnis/Kompression anhand der Endung wählen (GNU tar)
tar -xvf archiv.tar.gzEntpacken (Kompression wird automatisch erkannt)
tar -xvf archiv.tar.gz -C /ziel/In bestimmtes Verzeichnis entpacken
tar -xvf archiv.tar.gz pfad/datei.txtEinzelne Datei entpacken
tar -xvf archiv.tar.gz --strip-components=1Oberste Verzeichnisebene weglassen
tar -tvf archiv.tar.gzInhalt anzeigen
tar -rvf archiv.tar neue-dateiDatei anhängen (nur unkomprimiert)
tar -czf archiv.tar.gz --exclude='*.log' verzeichnis/Mit Ausschlüssen
tar -czf - verzeichnis/ | ssh host 'tar -xzf - -C /ziel'Verzeichnis per SSH übertragen
Optionen
-c / -x / -tErstellen / entpacken / auflisten
-f dateiArchivdatei (immer als letzte Kurzoption)
-vAusführlich
-z / -j / -Jgzip / bzip2 / xz
-C verzeichnisVorher in Verzeichnis wechseln
-pRechte beim Entpacken erhalten (als root Standard)

zip & unzip

BefehlBeschreibung
zip archiv.zip datei1 datei2Dateien packen
zip -r archiv.zip verzeichnis/Verzeichnis rekursiv packen
zip -r archiv.zip verzeichnis/ -x '*.log'Mit Ausschlüssen
zip -9 -r archiv.zip verzeichnis/Maximale Kompression
zip -u archiv.zip dateiDatei hinzufügen oder aktualisieren
zip -d archiv.zip datei.txtDatei aus Archiv entfernen
unzip archiv.zipEntpacken
unzip archiv.zip -d /ziel/In Verzeichnis entpacken
unzip -l archiv.zipInhalt anzeigen
unzip -t archiv.zipArchiv testen
unzip -o archiv.zipOhne Nachfrage überschreiben
unzip archiv.zip 'ordner/*'Nur Teile entpacken
zip -e archiv.zip dateienMit Passwort (schwache ZipCrypto-Verschlüsselung – für Vertrauliches 7z nutzen)

gzip, xz, zstd & 7-Zip

BefehlBeschreibung
gzip datei / gunzip datei.gzEinzelne Datei komprimieren / entpacken
gzip -k dateiOriginal behalten
zcat datei.gz / zless datei.gzKomprimierte Datei lesen
xz -T0 datei / unxz datei.xzMit allen Kernen komprimieren / entpacken
zstd datei / unzstd datei.zstzstd komprimieren / entpacken
bzip2 datei / bunzip2 datei.bz2bzip2 komprimieren / entpacken
7z a archiv.7z dateien7-Zip-Archiv erstellen
7z a -p -mhe=on archiv.7z dateienAES-256-verschlüsselt, auch Dateinamen verborgen
7z x archiv.7zMit Verzeichnisstruktur entpacken
7z l archiv.7zInhalt anzeigen
7z x archiv.rarRAR entpacken (7-Zip unterstützt RAR zum Lesen)
