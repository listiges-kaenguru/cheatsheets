Status & Dienst

BefehlBeschreibung
sudo systemctl enable --now fail2banDienst aktivieren und starten
sudo fail2ban-client statusListe der aktiven Jails
sudo fail2ban-client status sshdStatus eines Jails mit gesperrten IPs
sudo fail2ban-client bannedGesperrte IPs aller Jails
sudo fail2ban-client pingLäuft der Server?
sudo fail2ban-client reloadKonfiguration neu laden
sudo fail2ban-client reload sshdNur ein Jail neu laden
sudo fail2ban-client -tKonfiguration testen
sudo fail2ban-client -dEingelesene Konfiguration ausgeben (Fehlersuche)
sudo fail2ban-client versionVersion anzeigen

Sperren verwalten

BefehlBeschreibung
sudo fail2ban-client set sshd banip 203.0.113.7IP in einem Jail sperren
sudo fail2ban-client set sshd unbanip 203.0.113.7IP in einem Jail entsperren
sudo fail2ban-client unban 203.0.113.7IP in allen Jails entsperren
sudo fail2ban-client unban --allAlle Sperren aufheben
sudo fail2ban-client set sshd addignoreip 192.168.1.0/24Netz zur Laufzeit von Sperren ausnehmen
sudo fail2ban-client get sshd bantimeEinstellung eines Jails abfragen
sudo fail2ban-client stop sshd / sudo fail2ban-client start sshdEinzelnes Jail stoppen / starten

Dateien

Datei / PfadBeschreibung
/etc/fail2ban/jail.confStandardwerte – nicht bearbeiten, wird bei Updates überschrieben
/etc/fail2ban/jail.localEigene Einstellungen (überschreibt jail.conf)
/etc/fail2ban/jail.d/*.localEigene Jails als einzelne Dateien
/etc/fail2ban/filter.d/Filter (reguläre Ausdrücke für Logzeilen)
/etc/fail2ban/action.d/Aktionen (z. B. nftables, firewalld, Mail)
/var/log/fail2ban.logProtokoll von Fail2Ban

Konfiguration (jail.local)

OptionBeschreibung
[DEFAULT]Gilt für alle Jails
[sshd]Abschnitt für ein bestimmtes Jail
enabled = trueJail aktivieren
backend = systemdLogs aus dem Journal lesen (nötig, wenn keine Logdateien existieren)
port = sshZu sperrende Ports
logpath = /var/log/nginx/error.logZu überwachende Logdatei
maxretry = 5Fehlversuche bis zur Sperre
findtime = 10mZeitraum, in dem die Fehlversuche zählen
bantime = 1hSperrdauer (-1 = dauerhaft)
bantime.increment = trueSperrdauer bei Wiederholungstätern steigern
ignoreip = 127.0.0.1/8 ::1 192.168.1.0/24Nie sperren (eigenes Netz eintragen!)
banaction = nftables-multiportSperrmethode (auch firewallcmd-rich-rules, iptables-multiport)

Fehlersuche

BefehlBeschreibung
sudo fail2ban-regex /var/log/auth.log /etc/fail2ban/filter.d/sshd.confFilter gegen Logdatei testen
sudo fail2ban-regex systemd-journal sshdFilter gegen das Journal testen
sudo tail -f /var/log/fail2ban.logProtokoll live verfolgen
sudo journalctl -u fail2ban -fDienstmeldungen live verfolgen
sudo fail2ban-client set loglevel DEBUGAusführlichere Protokollierung
sudo nft list ruleset | grep -A5 f2bTatsächlich gesetzte Firewallregeln prüfen
