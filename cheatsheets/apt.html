Installieren & Aktualisieren

BefehlBeschreibung
sudo apt updatePaketlisten aktualisieren
sudo apt upgradeInstallierte Pakete aktualisieren (ohne Pakete zu entfernen)
sudo apt full-upgradeAktualisieren, auch wenn Pakete entfernt/neu installiert werden müssen
sudo apt install paketPaket installieren
sudo apt install ./paket.debLokale .deb-Datei inkl. Abhängigkeiten installieren
sudo apt install paket=1.2.3-1Bestimmte Version installieren
sudo apt install --no-install-recommends paketOhne empfohlene Zusatzpakete
sudo apt install --only-upgrade paketNur aktualisieren, falls schon installiert
sudo apt reinstall paketPaket neu installieren
sudo apt remove paketPaket entfernen, Konfiguration bleibt
sudo apt purge paketPaket inkl. Konfigurationsdateien entfernen
sudo apt autoremove --purgeNicht mehr benötigte Abhängigkeiten entfernen

Pakete suchen & Informationen

BefehlBeschreibung
apt search begriffIn Namen und Beschreibungen suchen
apt show paketDetails zu einem Paket
apt policy paketInstallierte und verfügbare Versionen mit Quelle
apt list --installedInstallierte Pakete
apt list --upgradablePakete mit verfügbaren Updates
apt-cache depends paket / apt-cache rdepends paketAbhängigkeiten / wer hängt davon ab
apt-mark showmanualManuell installierte Pakete
dpkg -l | grep nameInstallierte Pakete filtern
dpkg -L paketDateien eines installierten Pakets
dpkg -S /pfad/zur/dateiZu welchem Paket gehört eine Datei?
apt-file search dateinamePaket finden, das eine Datei enthält (auch nicht installiert; Paket apt-file)
zless /usr/share/doc/paket/changelog.Debian.gzChangelog eines Pakets

Paketquellen

BefehlBeschreibung
/etc/apt/sources.list.d/*.sourcesPaketquellen im deb822-Format (Standard ab Debian 13 und Ubuntu 24.04)
/etc/apt/sources.listKlassisches Einzeilenformat (älter)
sudo apt modernize-sourcesAlte Quellen ins deb822-Format umwandeln (ab APT 3.0)
/etc/apt/keyrings/Ablage für Signaturschlüssel von Fremdquellen (per Signed-By: einbinden)
sudo add-apt-repository ppa:name/ppaPPA hinzufügen (Ubuntu)
apt-keyVeraltet und in APT 3.0 entfernt – Schlüssel stattdessen unter /etc/apt/keyrings ablegen

Wartung & Fehlerbehebung

BefehlBeschreibung
sudo apt-mark hold paket / sudo apt-mark unhold paketPaket von Updates ausnehmen / wieder freigeben
apt-mark showholdGesperrte Pakete anzeigen
sudo apt --fix-broken installKaputte Abhängigkeiten reparieren
sudo dpkg --configure -aAbgebrochene Installationen fertig konfigurieren
sudo apt cleanHeruntergeladene Paketdateien löschen
sudo apt autocleanNur veraltete Paketdateien löschen
sudo dpkg-reconfigure paketPaket erneut konfigurieren (z. B. tzdata, locales)
/var/log/apt/history.logVerlauf aller Installationen und Updates
sudo unattended-upgrades --dry-run --debugAutomatische Sicherheitsupdates testen
[ -f /var/run/reboot-required ] && echo Neustart nötigPrüfen, ob ein Neustart erforderlich ist
