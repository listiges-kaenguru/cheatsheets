Inventar & Konfiguration

BefehlBeschreibung
ansible-inventory -i inventar.ini --graphGruppenhierarchie anzeigen
ansible-inventory -i inventar.ini --listInventar als JSON
/etc/ansible/hostsStandard-Inventar (statisch)
ansible.cfgProjekt-Konfiguration (im aktuellen Verzeichnis bevorzugt)
Beispiel inventar.ini
[web]Gruppe „web“
web1.example.orgHost in der Gruppe
web2 ansible_host=10.0.0.12 ansible_port=2222Host mit Adresse und Port
[web:vars]Variablen für die ganze Gruppe
ansible_user=deployVerbindungsbenutzer
[alle:children]Gruppe aus anderen Gruppen zusammensetzen
group_vars/web.yml / host_vars/web1.ymlVariablen je Gruppe / Host (empfohlen)

Ad-hoc-Befehle

BefehlBeschreibung
ansible web -a "uptime"Befehl ausführen (Modul command, Standard)
ansible web -m shell -a "ps aux | grep nginx"Shell mit Pipes/Umleitungen
ansible web -m ansible.builtin.copy -a "src=./app.conf dest=/etc/app.conf" -bDatei kopieren (-b = mit sudo)
ansible web -m ansible.builtin.package -a "name=nginx state=present" -bPaket installieren (distributionsübergreifend)
ansible web -m ansible.builtin.service -a "name=nginx state=restarted" -bDienst neu starten
ansible web -m ansible.builtin.systemd -a "name=nginx enabled=yes" -bDienst beim Boot aktivieren
ansible web -m ansible.builtin.user -a "name=deploy state=present" -bBenutzer anlegen
ansible web -m ansible.builtin.setupFakten (Systeminfos) eines Hosts sammeln
ansible web -m ansible.builtin.setup -a "filter=ansible_distribution*"Bestimmte Fakten filtern
ansible web -a "uptime" --limit web1 -b -KAuf einen Host beschränken, sudo-Passwort abfragen

BefehlBeschreibung

ansible-playbook site.yml --check --diffProbelauf mit Anzeige der Änderungen (nicht alle Module unterstützen es)
ansible-playbook site.yml --syntax-checkNur Syntax prüfen
ansible-playbook site.yml --list-tasks / --list-hostsAufgaben / Hosts anzeigen
ansible-playbook site.yml -l web --tags konfigAuf Gruppe und Tags beschränken
ansible-playbook site.yml --skip-tags downloadBestimmte Tags überspringen
ansible-playbook site.yml --start-at-task "Nginx installieren"An bestimmter Aufgabe beginnen
ansible-playbook site.yml -e "version=1.2.3"Zusätzliche Variablen übergeben
ansible-playbook site.yml --ask-vault-passVault-Passwort abfragen
ansible-playbook site.yml -b -KMit sudo (Privilegienerhöhung), Passwort abfragen
ansible-galaxy init rollennameVerzeichnisstruktur einer Rolle anlegen
ansible-lint site.ymlPlaybook auf gute Praktiken prüfen
