Crontab-Syntax

Tag und Wochentag werden ODER-verknüpft: 0 0 13 * 5 läuft am 13. und an jedem Freitag.

SyntaxBedeutung
* * * * * befehlMinute · Stunde · Tag · Monat · Wochentag · Befehl
Felder
Minute0–59
Stunde0–23
Tag1–31
Monat1–12 oder jan–dec
Wochentag0–7 (0 und 7 = Sonntag) oder sun–sat
Operatoren
*Jeder Wert
5Genau dieser Wert
1-5Bereich
1,3,5Liste
*/15Schrittweite (alle 15)
0-30/10Schrittweite innerhalb eines Bereichs (0, 10, 20, 30)

Befehle & Dateien

BefehlBeschreibung
crontab -eEigene Crontab bearbeiten
crontab -lEigene Crontab anzeigen
crontab -rEigene Crontab ohne Rückfrage löschen (Vorsicht, liegt neben -e)
crontab -l > crontab.bakCrontab sichern
crontab dateiCrontab aus Datei übernehmen
sudo crontab -u benutzer -eCrontab eines anderen Benutzers
/etc/crontab / /etc/cron.d/Systemweite Einträge – mit zusätzlichem Benutzerfeld vor dem Befehl
/etc/cron.hourly/ / /etc/cron.daily/Skripte stündlich / täglich (ohne Dateiendung, ausführbar)
/etc/cron.weekly/ / /etc/cron.monthly/Skripte wöchentlich / monatlich
run-parts --test /etc/cron.dailyZeigt, welche Skripte ausgeführt würden
journalctl -u cron / journalctl -u crondCron-Logs (Debian/Ubuntu / Fedora/RHEL)
grep CRON /var/log/syslogCron-Logs auf Systemen mit rsyslog

Umgebung & Stolperfallen

EintragBeschreibung
SHELL=/bin/bashShell festlegen (Standard ist /bin/sh)
PATH=/usr/local/bin:/usr/bin:/binCron hat einen sehr kurzen PATH – absolute Pfade verwenden
MAILTO="admin@example.org"Ausgaben per Mail senden; MAILTO="" deaktiviert Mails
CRON_TZ=Europe/BerlinZeitzone für die Einträge (cronie)
date +\%F% hat in Crontabs eine Sonderbedeutung und muss escaped werden
flock -n /tmp/job.lock befehlVerhindert, dass ein Job doppelt läuft

Beispiele

EintragAusführung
*/5 * * * * /pfad/skript.shAlle 5 Minuten
0 * * * * /pfad/skript.shStündlich zur vollen Stunde
0 2 * * * /pfad/skript.shTäglich um 2:00 Uhr
30 4 * * 0 /pfad/skript.shSonntags um 4:30 Uhr
0 9-17 * * 1-5 /pfad/skript.shWerktags stündlich von 9 bis 17 Uhr
0 0 1 * * /pfad/skript.shAm 1. jedes Monats um Mitternacht
0 3 1 1,4,7,10 * /pfad/skript.shQuartalsweise
@reboot /pfad/skript.shEinmal nach jedem Systemstart
@hourly / @daily / @weekly / @monthlyKurzformen (täglich = Mitternacht, wöchentlich = Sonntag 0:00)
0 2 * * * /pfad/skript.sh >> /var/log/skript.log 2>&1Ausgabe in Logdatei schreiben
0 2 * * * /pfad/skript.sh > /dev/null 2>&1Ausgabe verwerfen
