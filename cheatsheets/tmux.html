Sitzungen

Tastenkürzel beginnen mit dem Präfix Ctrl+b, danach die zweite Taste drücken.

BefehlBeschreibung
tmuxNeue Sitzung starten
tmux new -s nameBenannte Sitzung starten
tmux lsSitzungen auflisten
tmux attach -t name / tmux a -t nameAn Sitzung anhängen
tmux new -A -s nameAnhängen, falls vorhanden, sonst neu anlegen
tmux kill-session -t nameSitzung beenden
tmux kill-serverAlle Sitzungen beenden
tmux new -d -s name 'befehl'Sitzung im Hintergrund mit Befehl starten
tmux send-keys -t name 'befehl' EnterBefehl in eine laufende Sitzung schicken
Ctrl+b dSitzung trennen (Detach)
Ctrl+b sSitzungen auswählen
Ctrl+b $Sitzung umbenennen

Fenster

TastenkürzelBeschreibung
Ctrl+b cNeues Fenster
Ctrl+b n / Ctrl+b pNächstes / vorheriges Fenster
Ctrl+b 0Zu Fenster 0 wechseln (0–9)
Ctrl+b wFenster- und Sitzungsübersicht
Ctrl+b ,Fenster umbenennen
Ctrl+b &Fenster schließen

Bereiche (Panes)

TastenkürzelBeschreibung
Ctrl+b %Vertikal teilen (links/rechts)
Ctrl+b "Horizontal teilen (oben/unten)
Ctrl+b ←Zu Bereich in Pfeilrichtung wechseln
Ctrl+b oZum nächsten Bereich
Ctrl+b zBereich maximieren / wiederherstellen
Ctrl+b xBereich schließen
Ctrl+b SpaceLayout wechseln
Ctrl+b { / Ctrl+b }Bereich nach links / rechts tauschen
Ctrl+b !Bereich in eigenes Fenster verschieben
Ctrl+b qBereichsnummern anzeigen

Kopiermodus & Konfiguration

TastenkürzelBeschreibung
Ctrl+b [Kopier-/Scrollmodus (q beendet)
Ctrl+b ]Puffer einfügen
Ctrl+b :tmux-Befehlszeile
Ctrl+b ?Alle Tastenkürzel anzeigen
Ctrl+b tUhr anzeigen
~/.tmux.conf / ~/.config/tmux/tmux.confKonfigurationsdatei
set -g mouse onMaus (Scrollen, Bereiche anklicken) aktivieren
set -g history-limit 50000Größerer Scrollpuffer
set -g base-index 1Fensternummern ab 1
tmux source-file ~/.tmux.confKonfiguration neu laden
