Branches & Merging

BefehlBeschreibung
git branch / git branch -aLokale / alle Branches
git switch branchBranch wechseln (modern, statt git checkout)
git switch -c neuer-branchBranch anlegen und wechseln

git merge --abortMerge bei Konflikten abbrechen
git rebase mainAktuelle Commits auf main neu aufsetzen (saubere Historie)

git rebase --continue / --abortRebase fortsetzen / abbrechen
git cherry-pick commitEinzelnen Commit übernehmen

Rückgängig & Reparieren

BefehlBeschreibung
git restore dateiÄnderungen an Datei verwerfen (statt git checkout -- datei)
git restore --source=HEAD~2 dateiDatei aus älterem Commit holen
git reset --soft HEAD~1Letzten Commit lösen, Änderungen bleiben staged
git reset --mixed HEAD~1Letzten Commit lösen, Änderungen bleiben unstaged (Standard)
git reset --hard HEAD~1Letzten Commit und alle Änderungen verwerfen (Vorsicht!)
git revert commitCommit durch Gegen-Commit rückgängig machen (sicher für geteilte Historie)
git reflogVerlauf aller HEAD-Bewegungen – Rettungsanker für verlorene Commits
git reset --hard origin/mainLokalen Branch exakt auf den Remote-Stand setzen
git clean -nd / git clean -fdUnverfolgte Dateien anzeigen / löschen
