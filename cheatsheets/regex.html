Zeichen & Klassen

Die Syntax gilt für PCRE, JavaScript, Python und grep -E/grep -P. In Basis-Regex (grep, sed ohne -E) müssen + ? | ( ) { } mit Backslash geschrieben werden.

AusdruckBedeutung
.Beliebiges Zeichen außer Zeilenumbruch
\.Wörtlicher Punkt (Sonderzeichen mit \ escapen)
[abc]Eines der Zeichen a, b oder c
[^abc]Keines der Zeichen a, b, c
[a-z0-9]Zeichenbereich
\d / \DZiffer / keine Ziffer
\w / \WWortzeichen (Buchstabe, Ziffer, _) / kein Wortzeichen
\s / \SLeerraum (Leerzeichen, Tab, Umbruch) / kein Leerraum
[[:alpha:]] / [[:digit:]] / [[:space:]]POSIX-Klassen (grep, sed, awk)
\t / \n / \rTab / Zeilenumbruch / Wagenrücklauf
\p{L}Beliebiger Unicode-Buchstabe (PCRE, JS mit Flag u)

Anker & Grenzen

AusdruckBedeutung
^Anfang der Zeile bzw. des Strings
$Ende der Zeile bzw. des Strings
\bWortgrenze
\BKeine Wortgrenze
\A / \zAbsoluter Anfang / absolutes Ende des Strings (PCRE, Python)
\< / \>Wortanfang / Wortende (GNU grep, sed, vim)

Quantoren

AusdruckBedeutung
*0 oder mehr
+1 oder mehr
?0 oder 1 (optional)
{3}Genau 3
{3,}Mindestens 3
{3,5}3 bis 5
*? / +? / ??Genügsam (lazy): so wenig wie möglich
*+ / ++Possessiv: kein Backtracking (PCRE, Java)

Gruppen & Lookarounds

AusdruckBedeutung
(abc)Gruppe mit Erfassung
(?:abc)Gruppe ohne Erfassung
(?<name>abc)Benannte Gruppe
\1 / $1Rückreferenz im Muster / in der Ersetzung (je nach Werkzeug)
a|ba oder b
(?=abc)Positiver Lookahead: gefolgt von abc
(?!abc)Negativer Lookahead: nicht gefolgt von abc
(?<=abc)Positiver Lookbehind: vorausgegangen von abc
(?<!abc)Negativer Lookbehind

Flags

FlagBedeutung
iGroß-/Kleinschreibung ignorieren
gGlobal: alle Treffer (JS, sed)
mMehrzeilig: ^ und $ gelten je Zeile
sDotall: . passt auch auf Zeilenumbruch
xErweitert: Leerraum und Kommentare im Muster erlaubt (PCRE, Python)
uUnicode-Modus (JS)
(?i)musterFlag inline setzen

Beispiele

AusdruckFindet
^\s*$Leere Zeilen
^#.*Kommentarzeilen, die mit # beginnen
\b\d{1,3}(\.\d{1,3}){3}\bIPv4-ähnliche Adressen (prüft nicht auf ≤ 255)
^[^@\s]+@[^@\s]+\.[^@\s]+$Einfache E-Mail-Prüfung (keine vollständige RFC-Prüfung)
^\d{4}-\d{2}-\d{2}$Datum im Format JJJJ-MM-TT
^\d{5}$Deutsche Postleitzahl
https?://[^\s"']+URLs
^([0-9A-Fa-f]{2}:){5}[0-9A-Fa-f]{2}$MAC-Adresse
#[0-9a-fA-F]{6}\bHex-Farbwert
"[^"]*"Text in Anführungszeichen
^(?=.*\d)(?=.*[a-z])(?=.*[A-Z]).{12,}$Mind. 12 Zeichen mit Ziffer, Klein- und Großbuchstabe
