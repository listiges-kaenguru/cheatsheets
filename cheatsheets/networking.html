Schnittstellen & IP-Adressen

Linux mit iproute2. Die alten Befehle ifconfig, route, netstat und arp (net-tools) sind veraltet und oft nicht mehr installiert.

BefehlBeschreibung
ip -br aKurzübersicht aller Adressen
ip a show eth0Details einer Schnittstelle
ip -br linkSchnittstellen mit Status und MAC
sudo ip link set eth0 up / sudo ip link set eth0 downSchnittstelle aktivieren / deaktivieren
sudo ip addr add 192.168.1.10/24 dev eth0Adresse hinzufügen (nicht dauerhaft)
sudo ip addr del 192.168.1.10/24 dev eth0Adresse entfernen
hostname -IAlle eigenen IP-Adressen
ethtool eth0Linkgeschwindigkeit und Duplex
NetworkManager (dauerhaft)
nmcli device statusGeräte und Verbindungen
nmcli connection showGespeicherte Verbindungen
sudo nmcli con mod "LAN" ipv4.method manual ipv4.addresses 192.168.1.10/24 ipv4.gateway 192.168.1.1 ipv4.dns 192.168.1.1Statische IPv4-Konfiguration
sudo nmcli con up "LAN"Verbindung (neu) aktivieren
nmcli device wifi list / nmcli device wifi connect SSID --askWLANs anzeigen / verbinden
nmtuiTextoberfläche für NetworkManager
/etc/netplan/*.yaml / sudo netplan tryNetzwerkkonfiguration auf Ubuntu-Servern / testweise anwenden

Routing & Nachbarn

BefehlBeschreibung
ip routeRouting-Tabelle
ip -6 routeIPv6-Routing-Tabelle
ip route get 1.1.1.1Welche Route und Quelladresse wird genutzt?
sudo ip route add default via 192.168.1.1Standard-Gateway setzen
sudo ip route add 10.0.0.0/8 via 192.168.1.254 dev eth0Statische Route
sudo ip route del 10.0.0.0/8Route löschen
ip neighARP-/NDP-Tabelle (Nachbarn)
sudo sysctl -w net.ipv4.ip_forward=1IP-Weiterleitung aktivieren (Router)

Diagnose

BefehlBeschreibung
ping -c 4 hostErreichbarkeit prüfen (4 Pakete)
ping -6 hostÜber IPv6
tracepath host / traceroute hostRoute verfolgen
mtr hostTraceroute und Ping kombiniert, fortlaufend
ss -tulpnOffene TCP/UDP-Ports mit Prozess (ersetzt netstat)
ss -tn state establishedBestehende TCP-Verbindungen
dig example.orgDNS-Abfrage
dig +short example.org MXNur Ergebnisse eines Typs (A, AAAA, MX, TXT …)
dig @1.1.1.1 example.orgBestimmten DNS-Server fragen
dig -x 1.1.1.1Reverse Lookup
dig +trace example.orgAuflösung ab den Root-Servern verfolgen
resolvectl query example.orgAuflösung wie das System (systemd-resolved)
nc -zv host 22Ist ein TCP-Port offen?
nc -l 1234Auf Port lauschen (Testserver)
curl -I https://example.orgNur HTTP-Header
curl -v https://example.orgVerbindung, TLS und Header im Detail
curl -o datei https://example.org/dateiHerunterladen
curl -sS -X POST -H 'Content-Type: application/json' -d '{"a":1}' https://api.example.orgJSON-POST
curl --resolve example.org:443:10.0.0.5 https://example.orgAnfrage an bestimmte IP ohne DNS-Änderung
wget -c https://example.org/datei.isoDownload (fortsetzbar)
whois example.orgDomain- bzw. IP-Registrierungsdaten
