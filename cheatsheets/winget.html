Suchen & Informationen

winget ist in Windows 10/11 und Windows Server 2025 über den „App Installer“ enthalten. Mit --id … -e wird genau ein Paket ausgewählt.

BefehlBeschreibung
winget search begriffPakete suchen
winget show --id Git.GitDetails zu einem Paket
winget listInstallierte Programme (auch nicht über winget installierte)
winget list --upgrade-availableProgramme mit verfügbarem Update
winget --infoVersion, Pfade und Richtlinien anzeigen

Installieren & Aktualisieren

BefehlBeschreibung
winget install --id Git.Git -ePaket anhand der exakten ID installieren
winget install --id Git.Git -e --silentOhne Installationsdialog
winget install --id Git.Git -e --scope machineFür alle Benutzer installieren
winget install --id Git.Git -e --version 2.50.0Bestimmte Version installieren
winget install --id Git.Git -e --accept-package-agreements --accept-source-agreementsLizenzen automatisch akzeptieren (Skripte)
winget upgradeVerfügbare Updates anzeigen
winget upgrade --id Git.Git -eEin Paket aktualisieren
winget upgrade --allAlle Pakete aktualisieren
winget uninstall --id Git.Git -ePaket deinstallieren
winget pin add --id Git.GitPaket von Updates ausnehmen
winget pin list / winget pin remove --id Git.GitPins anzeigen / entfernen

Export, Quellen & Einstellungen

BefehlBeschreibung
winget export -o apps.jsonInstallierte Pakete exportieren
winget import -i apps.jsonPakete aus Exportdatei installieren
winget configure -f konfiguration.wingetRechner per Konfigurationsdatei (DSC) einrichten
winget source listPaketquellen anzeigen
winget source updateQuellen aktualisieren
winget source reset --forceQuellen zurücksetzen (bei Fehlern)
winget settingsEinstellungsdatei öffnen
