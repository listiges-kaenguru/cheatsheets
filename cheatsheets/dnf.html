Installieren & Aktualisieren

Fedora nutzt seit Version 41 DNF5. Die meisten Befehle sind mit DNF4 (RHEL, Rocky, Alma) identisch; Abweichungen sind vermerkt.

BefehlBeschreibung
sudo dnf upgrade --refreshPaketlisten neu laden und alles aktualisieren
sudo dnf check-upgradeVerfügbare Updates anzeigen
sudo dnf install paketPaket installieren
sudo dnf install ./paket.rpmLokale RPM-Datei inkl. Abhängigkeiten installieren
sudo dnf reinstall paketPaket neu installieren
sudo dnf downgrade paketAuf ältere Version zurückgehen
sudo dnf remove paketPaket entfernen
sudo dnf autoremoveNicht mehr benötigte Abhängigkeiten entfernen
sudo dnf group list / sudo dnf group install namePaketgruppen anzeigen / installieren
sudo dnf upgrade --securityNur Sicherheitsupdates einspielen

Suchen & Informationen

BefehlBeschreibung
dnf search begriffPakete suchen
dnf info paketDetails zu einem Paket
dnf provides /usr/bin/befehlWelches Paket liefert eine Datei?
dnf list --installedInstallierte Pakete (DNF4: dnf list installed)
dnf repoquery -l paketDateien eines Pakets
dnf repoquery --whatrequires paketPakete, die davon abhängen
rpm -qaAlle installierten RPMs
rpm -qi paketInformationen zu einem installierten Paket
rpm -ql paketDateien eines installierten Pakets
rpm -qf /pfad/zur/dateiZu welchem Paket gehört eine Datei?
rpm -V paketInstallierte Dateien gegen das Paket prüfen

Paketquellen & Verlauf

BefehlBeschreibung
dnf repolist --allAlle Paketquellen mit Status
sudo dnf config-manager addrepo --from-repofile=URLPaketquelle hinzufügen (DNF4: --add-repo URL)
sudo dnf config-manager setopt name.enabled=0Quelle deaktivieren (DNF4: --set-disabled name)
sudo dnf copr enable benutzer/projektCOPR-Repository aktivieren (Fedora)
sudo dnf install https://mirrors.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpmRPM Fusion (free) einrichten
/etc/yum.repos.d/Konfigurationsdateien der Paketquellen
dnf history listTransaktionsverlauf
dnf history info IDDetails einer Transaktion
sudo dnf history undo IDTransaktion rückgängig machen

Wartung & Systemupgrade

BefehlBeschreibung
sudo dnf clean allCaches leeren
sudo dnf makecacheMetadaten-Cache neu aufbauen
sudo dnf versionlock add paketVersion festhalten (DNF4: Plugin python3-dnf-plugin-versionlock nötig)
sudo dnf mark user paketPaket als manuell installiert markieren (DNF4: dnf mark install)
sudo dnf distro-syncPakete an die Versionen der Quellen angleichen
sudo dnf system-upgrade download --releasever=45Fedora-Versionsupgrade vorbereiten
sudo dnf offline rebootNeustarten und vorbereitetes Upgrade einspielen (DNF4: dnf system-upgrade reboot)
sudo rpm --rebuilddbBeschädigte RPM-Datenbank neu aufbauen
