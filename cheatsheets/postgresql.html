Rollen & Rechte

BefehlBeschreibung
CREATE ROLE app LOGIN PASSWORD 'Passwort';Anmeldbare Rolle (Benutzer) anlegen
CREATE ROLE leser;Gruppenrolle ohne Login
GRANT leser TO app;Rolle einer anderen zuweisen
GRANT CONNECT ON DATABASE shop TO app;Verbindungsrecht
GRANT USAGE ON SCHEMA public TO app;Schema nutzen dürfen
GRANT SELECT, INSERT, UPDATE, DELETE ON ALL TABLES IN SCHEMA public TO app;Rechte auf alle Tabellen
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT SELECT ON TABLES TO leser;Rechte auch für künftige Tabellen
ALTER ROLE app WITH PASSWORD 'NeuesPasswort';Passwort ändern
REVOKE INSERT ON kunden FROM app;Recht entziehen
DROP ROLE app;Rolle löschen
