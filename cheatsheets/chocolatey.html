Grundlagen

Chocolatey-Befehle in einer PowerShell als Administrator ausführen. Beschreibung gilt für Chocolatey 2.x.

BefehlBeschreibung
choco --versionInstallierte Version anzeigen
choco -? / choco install -?Hilfe allgemein / zu einem Befehl
choco search begriffIm Community-Repository suchen
choco info paketDetails zu einem Paket
choco listLokal installierte Pakete (in 2.x nur noch lokal)
choco outdatedPakete mit verfügbaren Updates
choco upgrade chocolateyChocolatey selbst aktualisieren

Pakete verwalten

BefehlBeschreibung
choco install paket -yPaket ohne Rückfrage installieren
choco install paket1 paket2 -yMehrere Pakete installieren
choco install paket --version=1.2.3 -yBestimmte Version installieren
choco install paket -y --params "'/Option:Wert'"Paketparameter übergeben
choco upgrade paket -yPaket aktualisieren
choco upgrade all -yAlle Pakete aktualisieren
choco uninstall paket -yPaket entfernen
choco pin add -n=paketPaket von upgrade all ausnehmen
choco pin list / choco pin remove -n=paketGesperrte Pakete anzeigen / Sperre aufheben

Quellen, Konfiguration & Export

BefehlBeschreibung
choco source listPaketquellen anzeigen
choco source add -n=intern -s="https://repo.example/nuget"Eigene Paketquelle hinzufügen
choco source disable -n=chocolateyQuelle deaktivieren
choco feature enable -n=allowGlobalConfirmation-y dauerhaft voraussetzen
choco config listKonfiguration anzeigen
choco export -o=pakete.configInstallierte Pakete in Datei exportieren
choco install pakete.config -yPakete aus Exportdatei installieren
C:\ProgramData\chocolatey\logs\chocolatey.logProtokolldatei
