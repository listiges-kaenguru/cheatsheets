Grundlagen

jq verarbeitet JSON zeilenweise über Filter. Beispiele mit jq 1.7. Filter immer in einfache Anführungszeichen setzen.

BefehlBeschreibung
jq . datei.jsonJSON einlesen und lesbar ausgeben (formatieren)
curl -s url | jq .Ausgabe eines Befehls formatieren
jq -c . datei.jsonKompakt, eine Zeile je Objekt
jq . datei.json > neu.jsonIn Datei schreiben
jq -r '.name' datei.jsonRohausgabe ohne Anführungszeichen (für Skripte)
jq -e '.aktiv' datei.jsonExit-Code passend zum Ergebnis (false/null → 1)
jq -n '{a:1, b:2}'JSON ohne Eingabe erzeugen
jq --arg name Max '.name=$name' datei.jsonShell-Variable sicher übergeben
jq --argjson n 5 '.anzahl=$n' datei.jsonZahl/JSON-Wert übergeben

Werte auswählen

BefehlBeschreibung
.feldWert eines Feldes
.a.b.cVerschachtelten Wert lesen
.["feld mit leer"]Feld mit Sonderzeichen im Namen
.feld?Kein Fehler, wenn das Feld fehlt
.array[0]Erstes Element
.array[-1]Letztes Element
.array[2:5]Teilbereich (Index 2 bis 4)
.array[]Alle Elemente einzeln ausgeben
.[]Alle Werte eines Objekts oder Arrays
.a, .bMehrere Werte
.a // "Standard"Ersatzwert, wenn null oder nicht vorhanden
..Rekursiv durch alle Werte absteigen

Umformen & filtern

BefehlBeschreibung
map(.preis)Feld aus jedem Array-Element
.array | map(.preis) | addWerte summieren
map(select(.aktiv))Nur Elemente behalten, bei denen aktiv wahr ist
.[] | select(.alter > 18)Nach Bedingung filtern
{name, email}Neues Objekt mit nur diesen Feldern
{name: .n, id: .id}Objekt mit umbenannten Feldern
.array | lengthAnzahl der Elemente
keys / valuesSchlüssel / Werte eines Objekts
.array | sort_by(.preis)Nach Feld sortieren
.array | group_by(.kategorie)Nach Feld gruppieren
.array | uniqueDuplikate entfernen
.array | min_by(.preis) / max_by(.preis)Kleinstes / größtes Element
to_entries | map({(.key): .value})Objekt in Schlüssel/Wert-Paare umwandeln
addZahlen summieren bzw. Objekte/Arrays zusammenführen
.array | .[] | .nameFilter mit Pipe verketten

BefehlBeschreibung
@csvArray-Zeile als CSV (mit -r)
@tsvAls tabulatorgetrennt
@jsonAls JSON-String kodieren
@base64 / @base64dBase64 kodieren / dekodieren
@shFür die Shell sicher zitieren
.array | map([.name, .preis]) | .[] | @csvTabelle als CSV ausgeben
tostring / tonumberIn Zeichenkette / Zahl umwandeln
ascii_downcase / ascii_upcaseKlein-/Großbuchstaben
split(",") / join(", ")String teilen / Array verbinden

gsub("alt"; "neu")Per Regex ersetzen
type / has("feld")Typ ermitteln / Feld vorhanden?
pathsAlle Pfade im Dokument auflisten
