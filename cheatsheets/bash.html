Bedingungen & Tests

SyntaxBeschreibung
if [[ bedingung ]]; then …; elif …; else …; fiVerzweigung ([[ ]] ist die Bash-Variante von [ ])
[[ "$a" == "$b" ]] / [[ "$a" != "$b" ]]Strings gleich / ungleich
[[ "$a" == *.txt ]]Mustervergleich (Glob, rechte Seite nicht quoten)
[[ "$a" =~ ^[0-9]+$ ]]Regex-Vergleich, Gruppen in BASH_REMATCH
[[ -z "$var" ]] / [[ -n "$var" ]]String leer / nicht leer
(( a == b )) / (( a < b ))Zahlenvergleich in arithmetischem Kontext
[ "$a" -eq "$b" ]Zahlen gleich (auch -ne, -lt, -le, -gt, -ge)
[[ -e pfad ]]Existiert
[[ -f pfad ]] / [[ -d pfad ]]Reguläre Datei / Verzeichnis
[[ -L pfad ]]Symbolischer Link
[[ -r pfad ]] / [[ -w pfad ]] / [[ -x pfad ]]Lesbar / schreibbar / ausführbar
[[ -s pfad ]]Datei existiert und ist nicht leer
[[ a -nt b ]]Datei a ist neuer als b
[[ bed1 && bed2 ]] / [[ bed1 || bed2 ]]Logisches UND / ODER
[[ ! bedingung ]]Negation
befehl && echo ok || echo fehlerKurzform, abhängig vom Exit-Code
