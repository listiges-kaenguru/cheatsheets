Schlüssel erzeugen & anzeigen

GnuPG (gpg) für OpenPGP-Schlüssel. Beispiele mit GnuPG 2.2+. Ein Schlüssel wird über seinen Fingerabdruck oder eine E-Mail angesprochen.

BefehlBeschreibung
gpg --full-generate-keySchlüssel interaktiv erzeugen (Typ „ECC“/Ed25519 wählen)
gpg --quick-generate-key "Max <max@example.org>" ed25519 sign,cert 2ySchlüssel ohne Rückfragen (2 Jahre gültig)
gpg --list-keysÖffentliche Schlüssel auflisten
gpg --list-secret-keys --keyid-format longPrivate Schlüssel mit langer ID
gpg --fingerprint max@example.orgFingerabdruck anzeigen (zum Abgleich)
gpg --edit-key max@example.orgSchlüssel bearbeiten (Unterschlüssel, Ablauf, Vertrauen)
gpg --gen-revoke max@example.org > widerruf.ascWiderrufszertifikat erzeugen (sicher aufbewahren!)
gpg --import widerruf.ascSchlüssel widerrufen (Zertifikat importieren)

Schlüssel austauschen

BefehlBeschreibung
gpg --armor --export max@example.org > public.ascÖffentlichen Schlüssel als Textdatei exportieren
gpg --armor --export-secret-keys max@example.org > private.ascPrivaten Schlüssel sichern (streng vertraulich!)
gpg --import public.ascSchlüssel importieren
gpg --export-ssh-key max@example.orgAls SSH-Public-Key ausgeben
gpg --keyserver hkps://keys.openpgp.org --send-keys FINGERABDRUCKAuf Keyserver hochladen
gpg --keyserver hkps://keys.openpgp.org --search-keys max@example.orgAuf Keyserver suchen
gpg --recv-keys FINGERABDRUCKSchlüssel per ID vom Keyserver holen
gpg --lsign-key max@example.orgSchlüssel lokal beglaubigen (Vertrauen setzen)
gpg --delete-key max@example.org / gpg --delete-secret-key max@example.orgÖffentlichen / privaten Schlüssel löschen

Verschlüsseln & Signieren

BefehlBeschreibung
gpg -e -r max@example.org dateiFür einen Empfänger verschlüsseln (erzeugt datei.gpg)
gpg -e -r a@x -r b@y dateiFür mehrere Empfänger verschlüsseln
gpg -d datei.gpg > dateiEntschlüsseln
gpg -c dateiSymmetrisch mit Passwort verschlüsseln (ohne Schlüsselpaar)
gpg -s dateiSignieren (binär, komprimiert)
gpg --clearsign datei.txtTextdatei mit lesbarer Signatur signieren
gpg --detach-sign --armor dateiGetrennte Signatur (datei.asc) erzeugen
gpg --verify datei.asc dateiGetrennte Signatur prüfen
gpg --verify datei.sigSignierte Datei prüfen
gpg -se -r max@example.org dateiSignieren und verschlüsseln in einem Schritt
gpg --armor -e -r max@example.org dateiVerschlüsselte Ausgabe als Text (.asc)

Agent, Vertrauen & Wartung

BefehlBeschreibung
gpg -k --keyid-format longSchlüssel-IDs für Konfigurationen ermitteln
gpg --edit-key max@example.org trustVertrauensstufe eines Schlüssels setzen
gpg --list-signatures max@example.orgBeglaubigungen (Signaturen) eines Schlüssels
gpg-connect-agent reloadagent /byegpg-agent neu laden
gpg-connect-agent "keyinfo --list" /byeVom Agent verwaltete Schlüssel anzeigen
echo "test" | gpg --clearsignPrüfen, ob Signieren (Passphrase-Abfrage) funktioniert
export GPG_TTY=$(tty)In .bashrc: nötig, damit die Passphrase-Abfrage im Terminal erscheint
git config --global user.signingkey FINGERABDRUCKGPG-Schlüssel für signierte Git-Commits hinterlegen
